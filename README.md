# Tutoriel de l’administration Chant d’orties

Ce dossier contient un guide autonome destiné à la personne qui gère le site.

## Ouvrir le tutoriel

Double-cliquer sur `index.html`. Aucune installation et aucune connexion ne sont
nécessaires pour lire le guide.

Le tutoriel fonctionne hors ligne. La connexion Internet n’est utile que lorsque la
personne ouvre ensuite la véritable administration pour modifier le site.

## Version illustrée

Aucun contenu de démonstration n’a été publié.

## Mettre le tutoriel à jour

1. Vérifier la version réellement déployée de l’administration.
2. Rejouer le scénario indiqué dans `sources/matrice-captures.md`.
3. Remplacer l’image en conservant son nom et ses dimensions.
4. Mettre à jour la date et la version dans ce fichier et dans l’en-tête du tutoriel.
5. Refaire les contrôles décrits dans `controle-livraison.md`.


## Vie privée

Ne jamais ajouter aux captures un mot de passe, un jeton, un identifiant technique,
une fenêtre de compte GitHub ou une information privée qui ne figure pas déjà sur le
site public.
